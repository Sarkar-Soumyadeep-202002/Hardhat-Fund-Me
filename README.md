💰 FundMe Smart Contract (DeFi DApp)

A decentralized funding application built using the Hardhat framework and Solidity, featuring two smart contracts that enable secure ETH contributions and owner-controlled withdrawals.

⚙️ Tech Stack

Solidity – Smart contract logic

Hardhat – Compilation, testing, and deployment environment

Node.js (JavaScript) – Deployment & unit testing scripts

Metamask – Wallet for interacting with the contract

Etherscan – Block explorer for contract verification

🧠 Project Overview

This project consists of two Solidity smart contracts:

FundMe.sol – The main contract allowing users to fund ETH into the contract and the owner to withdraw the accumulated balance.

HelperConfig.sol – A supporting contract for managing network configurations and dependencies during deployment.

The system is designed to demonstrate secure on-chain value transfer, ownership control, and decentralized participation.

🚀 Features

Accepts ETH contributions from any user

Owner-exclusive withdrawal functionality

Integrated unit testing and deployment via Hardhat

Supports local development networks and testnets

Verified and viewable transactions on Etherscan
